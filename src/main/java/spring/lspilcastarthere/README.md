# Spring Start Here (2021) — Personal Study Notes

## 📖 About This Repository
This repository contains personal study notes and technical documentation based on the 2021 book **"Spring Start Here"**.

The intent of these notes is to provide a highly visual, comprehensive reference guide. Rather than just summarizing the text, these notes actively map the book's foundational concepts to the actual under-the-hood mechanics of the Spring Framework. It utilizes heavily detailed Mermaid.js diagrams to illustrate architectural flows, application context bootstrapping, and bean lifecycles at a "source of truth" level.
